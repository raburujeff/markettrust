The problem

WhatsApp forwards are not civic infrastructure.

Traders lose money to unofficial fees, fake KRA texts, and tender “awards” because verifiable answers are hard to find under pressure.

  • Official portals exist — scattered, dense, easy to spoof
  • “Agents” and rumours fill the gap with confident wrong advice
  • No safe, simple path from doubt → verified next step → report

The solution

Find · Verify · Act

A WhatsApp-shaped assistant over a curated Kenya SME civic corpus — not an open-ended chatbot.

  • Ask — answer + trust label + public sources + next steps
  • Report — anonymous tip (privacy by default)
  • Cases — human triage handoff after intake

Why not ChatGPT?

Fluency is not trust.

General AI chat

Optimises for a confident answer. Can invent fees, portals, or refund steps. No civic reporting loop.

MarketTrust

Constrained corpus. Unmatched → Unclear. Sources + next steps. Anonymous Report → Cases. No API key for the PoC.

Real-world conditions

Built for how people decide under pressure.

  • Trust & verification — labels, sources, reviewed dates; Unclear when unmatched
  • Low bandwidth — static SPA; offline Ask from in-bundle corpus
  • Accessibility — plain-language mode, skip link, keyboard UI
  • Privacy — tips stay on-device for the PoC; anonymous by default
  • Multilingual — EN + SW now; FR / AR / PT + local languages on the path
  • Local relevance + next steps — Kenya seed; checklists + Report escalation
